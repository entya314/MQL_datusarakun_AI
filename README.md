## 自分のパソコンへ取得する方法

このリポジトリが GitHub などへ公開されたら、リポジトリの画面にある **Code** ボタンから URL をコピーします。

初めて取得する場合は、ターミナル（Windows では PowerShell または Git Bash）で次を実行します。

```bash
git clone <リポジトリのURL>
cd agri_app_ai
```

例（HTTPS）:

```bash
git clone https://github.com/<ユーザー名>/agri_app_ai.git
cd agri_app_ai
```

すでに一度 `clone` している場合は、プロジェクトのフォルダー内で更新を取得します。

```bash
cd agri_app_ai
git pull
```

> [!IMPORTANT]
> 現在はリモートリポジトリの URL が未設定です。GitHub などへの公開後に、実際の URL で `<リポジトリのURL>` を置き換えてください。
